# Hasil evaluasi responden (tidak diunggah ke Git)

Folder ini menampung jawaban nyata:

- `penilaian_relevansi.csv` — nilai 0/1/2 per responden, skenario, dan merchant
- `sus.csv` — jawaban 10 butir SUS dan skor
- `evaluasi_pengguna.db` — salinan SQLite dari kedua tabel (opsional)

Berkas muncul setelah responden menekan **Simpan** pada tab Evaluasi Pengguna.
Folder ini diabaikan `.gitignore` agar data sesi uji tidak ikut terunggah.

**Jangan** meniru nama berkas `data/evaluasi/contoh_penilaian_relevansi.csv`
atau `contoh_jawaban_sus.csv` — itu DATA TIRUAN untuk uji perangkat lunak saja.
