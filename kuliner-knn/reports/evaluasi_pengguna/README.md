# Laporan evaluasi pengguna

Berkas `*_responden.*` baru muncul setelah petugas menjalankan
`scripts/hitung_relevansi.py` dan `scripts/hitung_sus.py` pada data di
`data/evaluasi/hasil/`.

Berkas `*_contoh.*` dihasilkan dari **DATA TIRUAN**
(`data/evaluasi/contoh_*.csv`). Angka itu hanya untuk memastikan skrip
berjalan, **bukan** hasil uji responden, dan tidak boleh dikutip sebagai
capaian Precision@K, NDCG@K, atau SUS pada laporan TK2.
